# ТехноМастер

Учебное веб-приложение сервиса ремонта бытовой техники в Коченёво и Новосибирской области.

В проекте есть вызов мастера, каталог запчастей, корзина, оформление заказа и личные кабинеты клиента, мастера и администратора.

**Стек:** Next.js, TypeScript, Supabase, PostgreSQL.

```powershell
npm run dev
npm run lint
npm test
npm run build
```
