# Прецеденты учебного проекта

Эта таблица расширяет охват сценариев с учётом замечания преподавателя. Существующие отчёты не изменены. «Готово» означает наличие реализации в текущем коде; «План» — будущая функция.

| ID | Актор | Цель / основной сценарий | Альтернативы | Этап |
|---|---|---|---|---|
| UC-01 | Посетитель | Открыть главную и узнать регион работы | Нет подключения к БД: маркированные примеры | Готово |
| UC-02 | Посетитель | Посмотреть услуги и ориентировочные цены | Ошибка БД показана сообщением | Готово |
| UC-03 | Посетитель | Найти деталь по названию, категории, артикулу | Пустой результат, сброс поиска | Готово |
| UC-04 | Посетитель | Открыть деталь и посмотреть совместимость | Неактивная/несуществующая деталь: 404 | Готово |
| UC-05 | Клиент-гость | Заполнить контакты, технику, дату и время визита | Валидация телефона, даты, согласия | Готово |
| UC-06 | Клиент-гость | Отправить заявку, получить номер и статус | Ошибка сети/БД: сообщение, без ложного успеха | Готово |
| UC-07 | Администратор | Войти через Supabase Auth | Неверный пароль, неадминистративная роль | Готово |
| UC-08 | Администратор | Просмотреть свежие заявки и фильтр статуса | Нет записей; истёкшая сессия | Готово |
| UC-09 | Администратор | Обновить список после новой заявки | Сбой БД, повторная попытка | Готово |
| UC-10 | Администратор | Выйти и прекратить доступ в этом интерфейсе | Новая загрузка страницы требует входа | Готово |
| UC-11 | Администратор | Назначить или заменить мастера | Мастер недоступен | План |
| UC-12 | Мастер | Начать диагностику и изменить статус | Ожидание запчасти | План |
| UC-13 | Клиент | Перенести или отменить визит | Визит уже завершён | План |
| UC-14 | Клиент | Заказать запчасти и выбрать получение | Нет остатка, нужна проверка совместимости | План |
| UC-15 | Менеджер | Подтвердить заказ и стоимость | Частичная доступность деталей | План |
| UC-16 | Клиент | Оплатить подтверждённый заказ и получить чек | Платёж отклонён, повторное уведомление | План |
| UC-17 | Клиент | Подключить Telegram-уведомления | Бот заблокирован, связь отсутствует | План |
| UC-18 | Клиент | Оставить отзыв после ремонта | Повторный отзыв | План |
| UC-19 | Администратор | Управлять каталогом и остатками | Отрицательный остаток запрещён | План |

Для диаграммы прецедентов используйте отдельные акторы «Посетитель/клиент», «Мастер», «Администратор», а внешние Telegram и платёжную систему показывайте как будущие интеграции. Проверка данных — обязательная часть отправки заявки; получение подтверждения следует только после успешной записи в БД.
