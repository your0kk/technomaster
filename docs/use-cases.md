# Прецеденты учебного проекта

«Готово» означает наличие реализации в текущем коде; «План» — будущая функция.

| ID | Актор | Цель / основной сценарий | Альтернативы | Этап |
|---|---|---|---|---|
| UC-1 | Посетитель | Открыть главную и узнать регион работы | Нет подключения к БД: сообщение об ошибке | Готово |
| UC-2 | Посетитель | Посмотреть услуги и ориентировочные цены | Ошибка БД показана сообщением | Готово |
| UC-3 | Посетитель | Найти деталь по названию, категории, артикулу | Пустой результат, сброс поиска | Готово |
| UC-4 | Посетитель | Открыть деталь и посмотреть совместимость | Неактивная или несуществующая деталь: 404 | Готово |
| UC-5 | Клиент-гость | Заполнить контакты, технику, дату и время визита | Валидация телефона, даты, согласия | Готово |
| UC-6 | Клиент-гость | Отправить заявку, получить номер и статус | Ошибка сети или БД: сообщение, без ложного успеха | Готово |
| UC-7 | Клиент | Зарегистрироваться по имени, телефону, почте и паролю | Почта занята; пароли не совпадают | Готово |
| UC-8 | Клиент | Войти в личный кабинет | Неверная почта или пароль; сессия закончилась | Готово |
| UC-9 | Клиент | Посмотреть свои заявки и заказы | Список пуст; ошибка загрузки | Готово |
| UC-10 | Клиент | Изменить имя и телефон | Неверный формат телефона | Готово |
| UC-11 | Администратор | Войти через Supabase Auth | Неверный пароль, неадминистративная роль | Готово |
| UC-12 | Администратор | Просмотреть свежие заявки и фильтр статуса | Нет записей; истёкшая сессия | Готово |
| UC-13 | Администратор | Обновить список после новой заявки | Сбой БД, повторная попытка | Готово |
| UC-14 | Администратор | Выйти из кабинета | Требуется повторный вход | Готово |
| UC-15 | Администратор | Назначить или заменить мастера | Нужный мастер отсутствует в списке | Готово |
| UC-16 | Мастер | Начать диагностику и изменить статус | Ожидание запчасти | Готово |
| UC-17 | Клиент | Перенести или отменить визит | Визит уже завершён | План |
| UC-18 | Клиент | Заказать запчасти и выбрать получение | Нет остатка, нужна проверка совместимости | Готово |
| UC-19 | Менеджер | Подтвердить заказ и стоимость | Частичная доступность деталей | План |
| UC-20 | Клиент | Оплатить подтверждённый заказ и получить чек | Платёж отклонён, повторное уведомление | План |
| UC-21 | Клиент | Подключить Telegram-уведомления | Бот заблокирован, связь отсутствует | План |
| UC-22 | Клиент | Оставить отзыв после ремонта | Повторный отзыв | План |
| UC-23 | Администратор | Управлять каталогом и остатками | Отрицательный остаток запрещён | План |

Для диаграммы прецедентов используйте отдельные акторы «Посетитель/клиент», «Мастер», «Администратор», а внешние Telegram и платёжную систему показывайте как будущие интеграции. Проверка данных — обязательная часть отправки заявки; получение подтверждения следует только после успешной записи в БД.
