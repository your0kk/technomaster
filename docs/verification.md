# Проверка проекта

- `npm run lint` и `npm run typecheck` проходят без ошибок.
- `npm test` проходит: пять проверок миграций, RLS, создания заказа и валидации.
- Миграции применены к проекту Supabase `vgviitbgxstdjrdpijlr`.
- В Supabase проверены наличие `telegram_notifications`, функции `create_order` и RLS на `orders` и очереди уведомлений.
- У клиентского, административного и мастерского API проверяется JWT и роль до чтения или изменения служебных данных.
- `create_order` получает состав корзины только на сервере, проверяет остаток в транзакции, фиксирует цену позиции и уменьшает остаток детали.

Локальные ключи в `.env.local` и файлы с учебными паролями исключены из Git. Автоматический Telegram-бот, оплата и кассовый чек не подключены: база уже хранит очередь событий статусов для будущего бота.
