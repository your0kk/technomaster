# Проверка SEO и производительности

19 ноября 2026 года. Production-сборка Docker, nginx, локальный HTTPS. Lighthouse 13.5.0, Navigation, Desktop. Это лабораторные измерения на данном компьютере; они не заменяют статистику реальных пользователей.

13 публичных адресов из sitemap и 6 служебных страниц проверены по три раза (57 запусков). Для каждой категории взята медиана. Метрики взяты из запуска с медианной оценкой Performance; при равенстве выбран первый. Для трех кабинетов выполнено по одному запуску после входа. После исправления ARIA повторены три запуска страницы входа. Остальные страницы при этой правке не изменялись.

Основная серия относится к e06e7f0, проверка входа после исправления - к 1b75e72. Исходные отчеты сохранены в HTML; ниже ссылки на выбранные запуски. Прерывание CLI при одном запуске устранено повторным запуском, некорректный результат в итог не включен. Другие программы на компьютере не отключались.

## Дополнительные проверки

Проверены HTML и интерфейс 22 адресов: title, description в head, язык, H1, заголовки, alt, подписи полей, клавиатурный фокус, ширина 390px. Переполнений и незагруженных изображений не обнаружено. Проверка первых 12 переходов Tab не заменяет полный аудит доступности. Robots и sitemap возвращают собственное содержимое. В sitemap 13 публичных URL с example.com - временным доменом по заданию. Личные кабинеты, вход, корзина и формы имеют noindex и доступны для чтения роботом; API закрыт в robots. Это соответствует новой методичке; в предыдущей работе служебные страницы дополнительно запрещались через Disallow. Доступ к данным защищен авторизацией и RLS.

API проверен на ответы 400, 401, 403, 404, 413, 415; во всех есть X-Robots-Tag: noindex, nofollow. Неправильные запросы регистрации получили 400, затем 429, без создания пользователей.

Локальные LCP, CLS, INP и события взаимодействия измерены через web-vitals и PerformanceObserver при вводе и переключении элементов; результаты в results.json. Значение INP отсутствует, если в сценарии не было зарегистрировано подходящего события, и не приравнивается к нулю. Это программная проверка. Скриншоты панели DevTools Local Metrics/Interactions не получены из-за остановки управления Edge; этот пункт методички остается неподтвержденным. Скриншоты Lighthouse получены из настоящих HTML-отчетов.

Отчеты кабинетов содержат данные учетных записей и оставлены локально вне Git; опубликованы только оценки и метрики.

## Исправления и оставшиеся замечания

Обновлены Next.js и производственные зависимости; npm audit --omit=dev не нашел известных уязвимостей. Полный аудит сохраняет 14 предупреждений high в инструментах разработки. Исправлены контраст, favicon, загрузка локальных шрифтов, размещение метаданных, мобильное переполнение, резервирование места загрузки и ARIA переключателя входа.

Первый одиночный замер главной: P82/A95/BP96/SEO100, CLS0.213. Повторная медиана: 100/100/100/100. Исходный замер не был серией из трех запусков, поэтому это наблюдение до/после, а не строго контролируемый эксперимент. SEO карточки ранее 92, после переноса метаданных в head - 100.

Приоритет следующей доработки - стабильная геометрия загрузки кабинетов клиента и администратора: однократный Lighthouse CLS около 0.217 и 0.214. Далее - зависимости инструментов разработки и ручная проверка DevTools. Высокая оценка Lighthouse не доказывает отсутствие ошибок.

## Аналог

PageSpeed Insights для profi.ru, мобильные данные CrUX за 28 дней: LCP 1.9 с, INP 169 мс, CLS 0.11, FCP 1.2 с, TTFB 0.6 с. CWV не пройден из-за CLS. Лабораторная часть PSI завершилась ERR_TIMED_OUT. Скриншот field-данных приложен. Profi.ru выбран как сервис поиска специалистов, в том числе по бытовой технике. Его аудитория и масштаб отличаются.

Из сравнения следует: стабильность верстки важна даже при хорошем LCP; отзывчивость проверяют при взаимодействии, а не только при загрузке; локальные Desktop-замеры нельзя напрямую сравнивать с мобильной статистикой посетителей.
